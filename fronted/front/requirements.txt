# 前端项目依赖环境说明

## 项目概述
综测计算助手是一个基于Vue 3的高校综测智能计算系统，融合AI技术，解决传统综测评定中的痛点。

## Node.js版本要求
node>=16.0.0

## 项目依赖包详情

### 主要依赖包
vue@^3.5.22                    # Vue 3框架
vue-router@^4.5.1              # Vue路由管理
element-plus@^2.11.4           # Element Plus UI组件库
echarts@^6.0.0                 # ECharts数据可视化
axios@^1.12.2                  # HTTP客户端
pinia@^3.0.3                   # 状态管理

### 开发依赖包
@vitejs/plugin-vue@^6.0.1      # Vue插件支持
vite@npm:rolldown-vite@7.1.14  # 构建工具

## 安装步骤

1. 确保已安装Node.js (版本>=16.0.0)
2. 在项目根目录下执行以下命令安装依赖:
   ```
   npm install
   ```
3. 启动开发服务器:
   ```
   npm run dev
   ```
4. 构建生产版本:
   ```
   npm run build
   ```

## 环境变量配置

项目使用以下环境变量:
- VITE_API_BASE_URL: 后端API基础URL

在 .env、.env.development 和 .env.production 文件中配置相应环境的变量。
