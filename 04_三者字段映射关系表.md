# 三者字段映射关系表

## 1. 概述

本文档详细说明了Excel模板列、数据库字段、JSON响应三者之间的映射关系，重点关注综测成绩（ComprehensiveScore）、证书（Certificate）、加减分明细（ScoreDetail）等核心模型。

## 8. 数据流转图

### 8.1 Excel导入数据库流程

```
Excel文件
    ↓
[解析Excel] - 使用列标题变体识别
    ↓
[数据验证] - 必填字段、数值范围、一致性检查
    ↓
[数据转换] - Excel列 → 数据库字段
    ↓
[存储数据库]
    ├─→ students 表（学生信息）
    ├─→ comprehensive_scores 表（综测成绩）
    └─→ score_details 表（加减分明细）
```

### 8.2 数据库导出Excel流程

```
数据库
    ↓
[查询数据]
    ├─→ students 表
    ├─→ comprehensive_scores 表
    └─→ score_details 表
    ↓
[数据组装] - 数据库字段 → 标准字段名
    ↓
[填充Excel] - 标准字段名 → Excel列
    ↓
Excel文件
```

### 8.3 API响应数据流程

```
数据库
    ↓
[查询数据]
    ↓
[序列化为JSON] - 数据库字段 → JSON响应字段
    ↓
API响应
    ↓
前端展示
```

## 9. 关键计算公式

### 9.1 综测成绩计算公式

| 计算项 | 公式 | 说明 |
|--------|------|------|
| A类总分 | a_total_score = a1_score + a2_score + a3_score | 思想道德素质总分 |
| A类加权分 | a_weighted_score = a_total_score × (a_weight / 100) | 思想道德素质加权分（默认20%） |
| B类加权分 | b_weighted_score = b_raw_score × (b_weight / 100) | 学习成绩加权分（默认70%） |
| C类总分 | c_total_score = c1_score + c2_score + c3_score + c4_score | 素质拓展总分 |
| C类加权分 | c_weighted_score = c_total_score × (c_weight / 100) | 素质拓展加权分（默认10%） |
| 综测总成绩 | total_score = a_weighted_score + b_weighted_score + c_weighted_score | 综合测评总成绩 |

## 10. 字段映射注意事项

1. **列标题变体识别**：Excel导入时支持多种列标题变体，详见Excel模板结构文档
2. **数据类型转换**：Excel数值需要转换为数据库的FLOAT类型，注意精度问题
3. **必填字段验证**：student_id和student_name为必填字段
4. **唯一约束**：comprehensive_scores表的(student_id, semester, academic_year)组合唯一
5. **JSON字段**：details、ocr_result等JSON字段存储结构化信息
6. **时间戳**：所有表都有created_at和updated_at字段，使用自动时间戳
7. **软删除**：使用status字段标记状态，不进行物理删除
8. **版本控制**：学业成绩和综测成绩都有对应的历史记录表
