## 2. 存储方案说明

### 2.1 文件存储方式
采用**文件系统存储 + 数据库记录关联**的方式：

```
uploads/
└── certificates/
    ├── {year}/
    │   ├── {month}/
    │   │   └── {student_id}/
    │   │       ├── {certificate_id}/
    │   │       │   ├── image_001.jpg
    │   │       │   ├── image_002.jpg
    │   │       │   └── ...
    │   └── thumbnails/
    │       └── {student_id}/
    │           └── thumbnail_xxx.jpg
```

**优点：**
- 文件系统存储效率高，适合大文件
- 便于文件备份和迁移
- 数据库体积小， 查询性能好
- 支持缩略图生成， 提高预览加载速度

- 支持文件去重（通过MD5哈希）

### 2.2 文件命名规则
```
{student_id}/{certificate_id}/{uuid}.{ext}
```
**示例:**
```
202300502120/1/a1b2c3d4e5.jpg
```

### 2.3 文件去重机制
- 通过 `file_hash` 字段存储 MD5 哈希值
- 上传前计算文件哈希， 查询是否已存在相同文件
- 避免重复存储

## 4. 数据备份与恢复策略

### 4.1 数据库备份
```sql
-- 每日全量备份
sqlite3 database.db backup/database_$(date +%Y%m%d).db

-- 每周增量备份
-- 备份保留策略： 每日备份保留7天， 每周备份保留4周
```

**Python备份脚本示例:**
```python
import sqlite3
import shutil
from datetime import datetime
from pathlib import Path

def backup_database():
    source = Path('data/database.db')
    backup_dir = Path('backup/database')
    backup_dir.mkdir(parents=True, exist_ok=True)
    
    date_str = datetime.now().strftime('%Y%m%d')
    backup_file = backup_dir / f'database_{date_str}.db'
    
    shutil.copy2(source, backup_file)
    print(f'数据库备份完成: {backup_file}')

if __name__ == '__main__':
    backup_database()
```

### 4.2 文件备份
```bash
# 文件系统备份
rsync -av --delete uploads/certificates/ backup/certificates/$(date)/

# 或使用压缩备份
tar -czf uploads/certificates/ | gzip -9 > backup/certificates_$(date).tar.gz
```

### 4.3 恢复流程
1. **数据库恢复**: 直接复制备份文件覆盖当前文件
2. **文件恢复**: 从备份中恢复文件到上传目录
3. **验证恢复**: 检查数据完整性和一致性

## 5. 查询性能优化建议

### 5.1 分页查询
```python
# 使用 limit 和 offset
certificates = await Certificate.filter(student_id=student_id).offset(offset).limit(limit)
```

### 5.2 釶情加载
```python
# 使用 prefetch_related 鎷取关联图片
certificates = await Certificate.filter(student_id=student_id).prefetch_related("images")
```

### 5.3 缓存策略
- 对频繁访问的证书信息进行缓存
- 缓存过期时间: 5分钟
- 缓存更新策略: 写入时更新
