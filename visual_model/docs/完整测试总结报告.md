## 3. API接口清单梳理

### 3.1 接口分类统计

| 模块 | 接口数量 | 说明 |
|------|---------|------|
| 认证模块 | 10+ | 登录、注册、密码重置等 |
| 学生模块 | 20+ | 学生信息查询、管理等 |
| 教师模块 | 15+ | 教师管理功能 |
| 管理员模块 | 20+ | 系统管理功能 |
| 成绩上传模块 | 15+ | Excel上传、解析等 |
| 综测计算模块 | 20+ | 综测计算、配置等 |
| 证书模块 | 15+ | 证书上传、审核等 |
| 文件管理模块 | 10+ | 文件上传、下载等 |
| RAG AI模块 | 5+ | 智能问答功能 |
| **总计** | **130+** | |

### 3.2 主要API端点

#### 认证模块
- POST /api/v1/auth/login - 用户登录
- POST /api/v1/auth/register - 用户注册
- POST /api/v1/auth/logout - 用户登出
- POST /api/v1/auth/refresh - 刷新Token
- GET /api/v1/auth/me - 获取当前用户信息

#### 学生模块
- GET /api/v1/students - 获取学生列表
- GET /api/v1/students/{id} - 获取学生详情
- POST /api/v1/students - 创建学生
- PUT /api/v1/students/{id} - 更新学生信息
- DELETE /api/v1/students/{id} - 删除学生

#### 成绩上传模块
- POST /api/v1/score/upload - 上传成绩Excel
- GET /api/v1/score/parse - 解析成绩文件
- POST /api/v1/score/save - 保存成绩数据

#### 综测计算模块
- POST /api/v1/comprehensive/calculate - 计算综测成绩
- GET /api/v1/comprehensive/results - 获取综测结果
- GET /api/v1/comprehensive/config - 获取配置
- PUT /api/v1/comprehensive/config - 更新配置

#### 证书模块
- POST /api/v1/certificates/upload - 上传证书
- GET /api/v1/certificates - 获取证书列表
- PUT /api/v1/certificates/{id}/approve - 审核证书
