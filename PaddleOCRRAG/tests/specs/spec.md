# RAG检索准确性测试规范文档

## 1. 项目概述

### 1.1 目标
创建一个全面的RAG检索准确性测试文件，用于验证和评估RAG系统的检索质量，确保从知识库检索的信息准确、完整、可靠。

### 1.2 测试范围
- RAG知识库检索功能验证
- 文档内容读取与解析
- 多维度准确性校验
- 偏差分析与优化建议生成

### 1.3 相关文档路径
- 综合测评实施细则: `D:\PaddleOCR\PaddleOCRRAG\data\rules\03、计算机学院综合测评实施细则（2025）.docx`
- 学科竞赛名称列表: `D:\PaddleOCR\PaddleOCRRAG\data\rules\05、学科竞赛名称列表.xlsx`

## 2. 功能模块设计

### 2.1 模块一：RAG检索与输出模块

#### 2.1.1 功能描述
从RAG知识库执行检索操作，并完整打印输出检索结果。

#### 2.1.2 检索方式
1. **基础检索** (`search_relevant`)
   - 输入：查询文本、top_k参数
   - 输出：文档列表、元数据、距离分数

2. **类别感知检索** (`search_with_category_awareness`)
   - 输入：查询文本、top_k参数
   - 输出：重排结果列表、意图识别结果

3. **竞赛加分检索** (`search_competition_score`)
   - 输入：竞赛名称、获奖等级
   - 输出：检索结果、竞赛信息

4. **证书加分检索** (`search_certificate_score`)
   - 输入：证书名称
   - 输出：检索结果、证书信息

#### 2.1.3 输出格式
```
============================================================
  检索查询: [查询内容]
============================================================
检索耗时: XXX ms
返回文档数: X

[结果 1] 相似度: 0.XXXX (距离: 0.XXXX)
----------------------------------------------------------------------
元数据: {"type": "...", "category": "...", ...}
----------------------------------------------------------------------
文档内容:
[完整文档内容，不截断]
----------------------------------------------------------------------
```

### 2.2 模块二：文档读取模块

#### 2.2.1 DOCX文档读取
- 使用 `python-docx` 库读取Word文档
- 提取所有段落文本
- 识别文档结构（章节、标题、编号）
- 支持备用方案 `docx2txt`

#### 2.2.2 XLSX文档读取
- 使用 `openpyxl` 库读取Excel文档
- 自动识别表头行
- 提取竞赛名称、类别、级别等信息
- 构建竞赛记录列表

```
============================================================

文档总字符数: XXXX

  ...

关键章节识别:
  章节一: 内容预览...
  章节二: 内容预览...
```

| 相似度 | 与源文档内容的相似程度 | 文本相似度计算 |

### 2.4 模块四：偏差分析与优化建议模块

#### 2.4.1 问题分类

| 问题类型 | 严重程度 | 描述 |
|----------|----------|------|
| 检索无结果 | 高 | 查询无法返回任何相关结果 |
| 关键信息缺失 | 高 | 检索结果缺少关键数值或标准 |
| 类别不匹配 | 高 | 竞赛/证书类别识别错误 |
| 内容不完整 | 中 | 规则描述不完整 |
| 相似度低 | 中 | 检索结果与期望内容差异大 |
| 性能问题 | 低 | 检索耗时过长 |

#### 2.4.2 优化建议生成规则

1. **检索无结果**
   - 检查文档是否已正确向量化
   - 验证向量数据库连接状态
   - 检查查询语句是否过于模糊

2. **关键信息缺失**
   - 检查向量切片是否包含完整信息
   - 调整chunk_size参数（当前500字符）
   - 增加chunk_overlap（当前50字符）

3. **类别不匹配**
   - 更新竞赛映射表配置
   - 增强类别关键词库
   - 检查Excel数据完整性

4. **内容不完整**
   - 优化文档切片策略
   - 增加切片重叠区域
   - 考虑按章节切分

5. **相似度低**
   - 检查嵌入模型质量
   - 调整相似度阈值
   - 优化查询增强策略

6. **性能问题**
   - 优化向量索引
   - 减少返回数量
   - 考虑使用GPU加速

## 6. 异常处理规范

### 6.1 文件读取异常
- 文件不存在: 记录错误，返回失败状态
- 格式不支持: 尝试备用方案，记录警告
- 编码错误: 使用UTF-8强制解码

### 6.2 RAG系统异常
- 初始化失败: 记录详细错误信息，终止测试
- 检索失败: 记录错误，返回空结果
- 连接超时: 记录警告，重试一次

### 6.3 数据处理异常
- 数据格式错误: 跳过当前记录，继续处理
- 空数据处理: 记录警告，使用默认值
